# 视觉风格规格（ Style Spec ）

> 本文件是 `dark-field-explainer-video` 的**美术宪法**。所有数值来自对参考片
> `assets/「我爱你」说到第 1000 遍，信息量几乎为零.mp4` 的抽帧逆向与实测复现。
> 改任何一个值之前，先问自己：**改完更像参考片了，还是更远离了？**

## 0. 参考片基线

| 项 | 值 |
|---|---|
| 分辨率 | 1920×1080 |
| 帧率 | 30 fps |
| 时长 | 164 s |
| 视频码率 | ≈ 10.9 Mbps（`libx264` High profile） |
| 音频 | AAC 48kHz stereo 267 kbps（旁白 + 衬乐） |
| 色彩空间 | `yuvj420p`（full range），色域 `bt470bg` |

> **注意**：参考片用了 10.9 Mbps。这类大面积近黑的画面，**低码率会出现明显色带（banding）**，
> 因此本 skill 的编码建议值是 **8M**，低于 6M 时应在暗部加噪点（本模板已带颗粒层，属于双重保险）。

| 类目灰 | `#d0d0d6` | 图表类目文字（比次级灰亮一档） |
| 弱化灰 | `#5a5a62` | 提示行、脚注级信息 |
| 描边灰 | `#2e2e36` | 圆角边框、分隔线 |

### 1.2 强调色（画面 5% 的面积，稀缺才有力量）

| Hex | 用途 |
|---|---|
| `#ff4d2b` | 变量基准值 |
| **`#ff6a45`** | **实际用色**（`#ff4d2b` 在纯黑上偏暗，提亮后观感与参考片一致） |

**只允许给三样东西**：

3. 画面的当前焦点（左上角的时间标签「第 1000 遍」）

### 1.3 背景


颗粒层用内联 SVG data-URI 平铺。**没有它，画面会"塑料感"十足。**

## 2. 字体系统

```css
.serif { font-family: "Source Han Serif SC","Noto Serif SC","Songti SC","STSong","SimSun",serif; }
.sans  { font-family: "PingFang SC","Microsoft YaHei","Hiragino Sans GB",sans-serif; }
```

| 场景 | 字体 | 附加处理 |
|---|---|---|
| 衬线大标题 | serif | `-webkit-text-stroke: .6px rgba(255,255,255,.16)`（Windows 宋体偏细，微补一档） |
| 数学公式 | serif + `font-style: italic` | 下标用 Unicode（如 `log₂ p`） |
| 标签 / 单位 | sans | `letter-spacing: 6~8px`（拉开才有设计感） |
| 字幕 | sans 500 | 强调词用 `em` + 橙 |

**Windows 提示**：优先档 `Source Han Serif SC` 通常没有，会落到 `SimSun`。若成品大标题过细，
优先用 `font-weight: 700`，其次才是 `-webkit-text-stroke`。

## 3. 发光配方

强调色（三层，缺一不可）：

```css
.glow-r {
  text-shadow: 0 0  16px rgba(255,86,50,.60),
               0 0  54px rgba(255,70,40,.38),
               0 0 110px rgba(255,60,30,.20);
}
```

白色（收敛版，用于衬线大标题）：

```css
.glow-w {
  text-shadow: 0 0 14px rgba(255,255,255,.40),
               0 0 46px rgba(255,255,255,.20);
}
```

> **绝对禁止**用 `-webkit-text-stroke` 或 `paint-order` 冒充发光——那叫描边，观感廉价。
> 发光的本质是**光晕扩散**，必须是多层递减的 `text-shadow`。

## 5. 三层结构语法（Layering）

> 参考片几乎找不到「纯黑底 + 孤立几行字」的镜头——它的每一幕都是 **2~3 层的叠合**：
> 背景给密度与质感，中景给论证，前景给焦点。**层数是这套语言与「PPT 换黑底」的分水岭**，
> 本节是 SKILL.md 硬规则 ⑧ 的完整展开。以参考片开场为例：140~160 枚带时间戳小字的漂浮气泡（L1）
> + 圆角框与说明文字（L2）+ `≈ 0 bit` 发光大数字与字幕（L3）。

### 5.1 三层的分工

| 层 | 职责 | 存在感 | 承载元素 |
|---|---|---|---|
| **L1 背景层** | 密度与质感，让黑"不死" | **5% ~ 20%** | 漂浮消息气泡（参数见 §7.1，含每枚下方的时间戳小字）、点阵网格（见 §5.3，降透明度时）、弱流场（参数同 §7.2，线 alpha 压到 ≤0.18）、暗淡底纹 |
| **L2 中景层** | 承载论证，撑住"信息量" | 抢不过 L3 即可 | 柱状图（§4.2 B）、点阵进度、进度格、账本矩阵、微光条目卡（见 §5.4） |
| **L3 前景层** | 发光焦点 | 一屏只有一个 | 大发光数字 / 关键词 + 底部字幕（§8） |

- L1 **永远不许抢戏**：单元素透明度压在 0.05~0.22，整体存在感 5%~20%。
- L2 是数据可视化的家，论证类幕（对比 / 分布 / 账目）靠它立住。
- L3 就是 §4.2 各实测表里的主数字 / 大标题，加上 §8 的字幕。

### 5.2 层数纪律

- **一幕 ≥ 2 层**（L1 + L3 是下限），三层是数字幕 / 数据图幕的常态。
- 钩子幕与情绪粒子幕也不豁免：钩子幕 = 气泡层 + 文字，情绪粒子幕 = 流场 + 文字，恰好两层。
- **唯一例外是幕与幕之间的黑场转场**——纯黑只属于转场，不是任何一幕的常态。

### 5.3 组件库 · 点阵网格（Dots Grid）

把「占比 / 概率」翻译成格子矩阵（10×10 = 100 格，一格 = 1%）。常作 L2 中景；透明度减半后也可作 L1 背景。

```css
.dots{display:grid;grid-template-columns:repeat(10,24px);gap:12px}
.dots i{width:24px;height:24px;border-radius:4px;background:rgba(255,255,255,.06)}
.dots i.on{background:rgba(255,106,69,.24)}   /* #ff6a45，透明度在 0.15~0.3 间取值 */
```

```js
/* 逐格渐次点亮：每格错峰 0.03~0.06s（此处取 0.045s），i 为格序号；tw 见 scene-patterns.md 通用约定 */
cells.forEach((c, i) => c.style.opacity = tw(p, .20 + i*.045, .34 + i*.045));
```

规格：N×M 格（常用 10×10）；单格 18~28px、间距 10~14px、圆角 4px；未点亮格 `rgba(255,255,255,.06)`；
点亮格 `#ff6a45` 带 **0.15~0.3 透明度**渐次点亮，每格错峰 **0.03~0.06s**。

### 5.4 组件库 · 微光条目卡（Glow Row）

「列举幕」的反 PPT 强化：把裸文字行容器化，每条垫一层几乎不可见的圆角条。

```css
.rows{display:flex;flex-direction:column;gap:14px}
.rows .row{display:flex;align-items:baseline;gap:22px;padding:14px 26px;
  border-radius:10px;background:rgba(255,255,255,.025);
  font-size:30px;line-height:1.6;color:#f2f2f4}
.rows .no{font-size:24px;color:#8a8a92;letter-spacing:2px;min-width:2.2em}   /* 两位零填充序号 */
.rows .row.focus .no,.rows .row.focus .tx{color:#ff6a45}                     /* 仅一条可点亮 */
```

```js
/* 逐条错峰 0.2~0.3s 入场：opacity 0→1 + translateX 24px→0（此处取 0.24s 错峰） */
rows.forEach((r, i) => {
  r.style.opacity   = tw(p, .16 + i*.24, .34 + i*.24);
  r.style.transform = `translateX(${24*(1 - easeOut((p - .16 - i*.24) / .18))}px)`;
});
```

规格：每条 = **两位零填充编号**（等宽或 sans，灰，焦点条为橙）+ **条目文字**（白 `#f2f2f4` 或次级灰）；
整体垫 `rgba(255,255,255,.025)` 圆角条（radius 8~12px，内边距使行高 **≥1.6**）；
逐条错峰 **0.2~0.3s** 入场（opacity 0→1 + translateX 24px→0）；**仅一条可点亮为橙色焦点**。

### 5.5 大字压场可读性：渐晕，不是底色块

大数字 / 大标题直接压在粒子、流场、气泡层上时，**禁止给文字加实底色块**
（`background: rgba(10,10,12,.66)` 之类——那是一块补丁，会切断背景层的连续感，观感立刻回到 PPT）。
正确手法：在**背景层之上、文字之下**垫一层中央径向压暗渐晕，让文字所在区域整体暗下去：

```css
.vignette{position:absolute;inset:0;
  background:radial-gradient(ellipse 62% 55% at 50% 50%, rgba(10,10,12,.62) 0%, rgba(10,10,12,.38) 45%, transparent 72%);
  pointer-events:none}
```

渐晕是"场本身暗了一块"，文字依旧与背景同呼吸；实底色块是"贴了一张纸"。务必用前者。

## 6. 节奏与时间值

| 参数 | 取值 | 说明 |
|---|---|---|
| 幕长 | 6 ~ 12 s | 低于 6s 念不完一句，高于 12s 观众开始走神 |
| 总时长 | 150 ~ 180 s | 与系列其余成品对齐 |
| 幕尾淡出 | 0.35 s | `clip((p-.94)/.06)` |
| 幕头淡入 | 0.35 s | `easeOut(p/.04)` |
| 元素入场错峰 | 0.15 ~ 0.3 s | 幕内元素**绝不同时出现**，必须逐个登台 |
| 黑场长度 | ≥ 0.3 s | 参考片黑场远不止此（30s 附近整屏只剩两个字），偏长永远比偏短安全 |

### 幕内元素的标准登场序列

以数字幕为例（`p` = 幕内进度 0~1）：

```
p .04~.18  顶部标签（先定场景/时间）
p .10~.30  容器框（缓慢 scale .94 → 1.0）
p .20~.44  框内大标题（上浮 26px）
p .44~.56  说明文字
p .54~.76  主数字（缩放 .86 → 1.0 弹性落地）
p .74~.88  字幕
```

### 缓动

```js
const easeOut = v => 1 - Math.pow(1 - clamp(v), 3);   // 主力：慢出
const easeIO  = v => v<.5 ? 4*v*v*v : 1-Math.pow(-2*v+2,3)/2;  // 仅用于容器 scale
```

## 7. 动态背景层

### 7.1 漂浮消息层（用于"信息/对话/重复"主题）

```js
// 解析式位置 —— 天然满足「同 t 同画面」
const y = ((b.y - b.sp * t) % span + span) % span - b.h;
```

| 参数 | 值 |
|---|---|
| 数量 | 140 ~ 160 |
| 速度 | 16 ~ 46 px/s（向上） |
| 单元素透明度 | 0.05 ~ 0.22 |
| 气泡填充 | `rgba(255,255,255,.055)`，圆角 = 高度一半 |
| 文字 | `rgba(255,255,255,.42)`，17 ~ 24px |

参考片的技巧：气泡下方还有一行更小的暗色时间戳（`8:01 015`），
**这行小字是"密度感"的来源**，别省。

### 7.2 流场粒子（情绪镜头）

**核心思路：极角偏转 + 双正弦扰动即可，不必引入 Perlin/Simplex 噪声库。**

```js
const dx = p.x - 960, dy = p.y - 540;
const r  = Math.hypot(dx, dy) + 1e-6, ang = Math.atan2(dy, dx);
const a  = ang + 1.05
         + Math.sin(r*0.0074 - t*1.6) * 0.62      // 径向波：制造疏密条纹
         + Math.cos(ang*2.7 + t*1.1) * 0.36;      // 角向抖动：制造发丝弯曲
p.x += Math.cos(a) * 7.5;  p.y += Math.sin(a) * 7.5;
```

| 参数 | 值 | 备注 |
|---|---|---|
| 粒子数 | 1000 | 少于 600 出不来丝感，多于 1500 会糊成网 |
| 步长 | 7.5 px / step | 步长越大，拖尾越"甩" |
| **基角偏移** | **+1.05 rad** | ⚠️ 这是"向外飞散"还是"原地绕圈"的分水岭。取 1.42 时切向占主导，粒子绕圈 → 长时间重演后会卷成一个明显的涡核，丢掉发丝感 |
| 拖尾 | 每步盖 `rgba(10,10,12,0.042)` | **这个 alpha 是丝线长度的总开关**。0.030 太长（同样会绕成涡核），0.06 以上则没有丝感 |
| 线宽 | 1.25 | 超 1.6 变毛糙 |
| 单次描边 alpha | 0.30 | |
| 重生区 | 画面中心 ±310px | 越界粒子回中心 → 形成"中心密、四周散"；范围过小会快速堆成一点 |
| 调色板 | `#2ee6b0 #ff7a55 #e07aa8 #9dc0ff #e8e8ee #4dd0c0` | 低饱和冷色为主，橙只占少量 |

> **调参口诀**：线条太"卷" → 调大基角偏移；线条太"糊" → 调大清屏 alpha；
> 中心太空 → 调大基角；中心太挤 → 扩大重生区。一次只动一个参数，用 SKILL.md 阶段 5 的抽帧目检对比。

**确定性保障**：逐帧渲染时不能依赖上一帧残留。宿主以固定步长 `1/30` 把场推进到目标时刻：

```js
function seekFlow(target){
  if (target < flow.simT - 1e-6 || target - flow.simT > 0.6) resetFlow();
  let g = 0;
  while (flow.simT + 1/30 <= target + 1e-6 && g++ < 900) stepFlow();
}
```

`resetFlow()` 必须用**固定种子**重建粒子与随机序列（模板用的 `mulberry32(20261014)`），
否则抽帧时的粒子分布会与全量渲染对不上。实时预览时 `t` 递增，每帧只补 ~1 步；抽帧跳播时自动 reset 重演。
**两边结果完全一致。**

## 8. 字幕规范

```css
#sub {
  bottom: 44px;  font-size: 34px;  letter-spacing: 1px;  font-weight: 500;
  color: #ececf0;  text-align: center;
}
#sub em { font-style: normal; color: #ff6a45; font-weight: 700; }
```

- 一行，**不超过 20 个字**
- 每幕一条，落在幕进度 `p .74~.88` 入场（**先给画面，后给字幕**，让视觉先立住）
- 句中**至多一个**强调词，多了就失去焦点

## 9. 反面清单（出现任一即视为失败）

| ❌ | ✅ |
|---|---|
| 屏幕塞满文字 | 信息区占 40~60%，四周留空 |
| 标题、数字、图标全是橙色 | 橙只给一个焦点 |
| `-webkit-text-stroke` 冒充发光 | 三层 `text-shadow` |
| 加入第三种字体 | 衬线 + 无衬线，各一套 |
| 幕之间连续不断 | 黑场起码 0.3s |
| 元素同时出场 | 错峰 0.15~0.3s |
| 6Mbps 以下编码暗场 | 8M，且保留颗粒层 |
| 用 `text-align: left` 排主标题 | 主信息一律居中，仅辅助信息左齐 |
| bullet 列表用「•」 | 用序号或留白分层，参考片通篇不用项目符号 |
| 纯黑底 + 孤立几行字的「空洞幕」 | 每幕 ≥2 层，背景永远有暗纹理/粒子/点阵 |
| 给压场文字垫实底色块 | 中央径向压暗渐晕（文字区局部暗化） |
