# 分幕套路（Scene Patterns）

七套模板覆盖了参考片的所有镜头类型。**拿到一个主题，先拿这套拼装一遍**，再去改细节。

通用约定：`p` = 幕内进度 0~1。所有幕统一使用（模板已内置）：

```js
const clamp = v => v < 0 ? 0 : v > 1 ? 1 : v;
const easeOut = v => 1 - Math.pow(1 - clamp(v), 3);
const tw = (p,a,b) => easeOut((p-a)/(b-a)) * (1 - clamp((p-.93)/.07));  // 入场+尾段淡出
const sceneOp = p => easeOut(p/.04) * (1 - clamp((p-.94)/.06));          // 幕透明度（黑场转场）
```

---

## 1. 数字幕 · Number

**用途**：把一个抽象结论换算成一个具体数字。整套风格的主力镜头。
**参考**：参考片「≈ 0 bit」、「0.35 bit」。

```
      顶部小标签（橙）                     ← p .04~.18
   ┌──────────────────┐
   │                  │                   ← 容器框 p .10~.30, scale .94→1
   │    大标题/主词    │  158px serif     ← p .20~.44, 上浮 26px
   │                  │
   └──────────────────┘
          说 明                            ← p .44~.56
       ≈ 主 数 字                           ← p .54~.76, scale .86→1
```

```html
<div class="cap">第 1000 遍</div>
<div class="box"><div class="title serif">我爱你</div></div>
<div class="lbl">信息量</div>
<div class="bit">≈ 0 bit</div>
```

```css
.cap  { top:150px;  font-size:40px; color:var(--accent); letter-spacing:3px }
.box  { top:227px;  width:620px; height:350px; margin-left:-310px;
        border:3px solid #2e2e36; border-radius:46px; background:rgba(255,255,255,.012) }
.title{ font-size:158px; color:#b9b9c1; letter-spacing:8px }
.lbl  { top:648px;  font-size:34px; color:var(--ink-dim); letter-spacing:6px }
.bit  { top:700px;  font-size:118px; font-weight:700; color:#ff6a45; text-shadow: …三层… }
```

> **数字必须带单位**（`bit` / `天` / `次`），裸数字没有说服力。

## 2. 对比幕 · Compare

**用途**：两个同质数字并置，用落差制造冲击。参考片用「第 1 天 → 第 1000 遍」做时间轴对比。

```
        A                    B
     标签A                 标签B        ← p .06~.22
    大字A  (灰)      ──    大字B  (橙)  ← 错峰 0.12s
     单位A                 单位B
            ─── 分隔线 ───               ← p .40~.55 从中心向两侧展开
               结 论                      ← p .60~.80
```

实现要点：
- 两侧字号必须相同，只靠**颜色**（灰 vs 橙）区分胜负
- 分隔线用 `scaleX(0→1)` + `transform-origin:center`
- 结论行用 sans 500，比两侧小一号，颜色 `#eaeaee`

## 3. 公式幕 · Formula

**用途**：给这套语言上"科学信用"。参考片用 `H = −Σ p · log₂ p` 压场。

```
              H  =  −Σ p · log₂ p                ← 84px serif italic, p .02~.20
   ① p 是概率        ② log 是"意外程度"        ③ Σ 是把所有可能加起来
          （逐条错峰弹出，每条只 2~4 个字）      ← p .28/.42/.56
```

- 衬线 + 斜体，**符号务必用 Unicode 真符号**（`Σ` `·` `₂` `≈` `−`），别用字母拼凑
- 注解条三列等宽，颜色 `#8a8a92`，比公式小一半以上
- 公式本身**不要加发光**，让它保持冷静；发光留给数字幕

## 4. 数据图幕 · Chart

**用途**：把分布摊开给人看。参考片「晚安 95% / 嗯 4.1% / 好 0.9% …」。

```
                公式/标题                        ← p .02~.20
   ▁              █                               
   █ 其余 8 项，宽度 ≤130，间距 24，色 #8a8a92     ← 生长动画 scaleY 0→1, p .24~.70
   晚安  嗯  好  哈哈  在吗  到了  吃了  睡了
                                    
                提示行                            ← p .40~.54
                                    ┌──────┐
                                    │ 熵   │  34px
                                    │ 0.35 │ 130px 橙
                                    │ bit  │  30px
                                    └──────┘      ← p .58~.84
```

```js
// 柱高：以最大值为基准单位，避免小值完全不可见
const MAXH = 500, UNIT = MAXH / 95;
bar.style.height = Math.max(4, value * UNIT * growProgress) + 'px';
```

关键点：
- **小值要给 4px 兜底高度**，否则 0.3% 的柱子会消失，反而看不出"低到几乎不存在"
- 百分比标签必须在**柱顶上方**，不能压在柱子里
- 图表右侧留出独立区域放关键数字，**这个数字才是一幕的落点**

## 5. 列举幕 · List

**用途**：并列多个同构条目。**本风格的最大陷阱**——很容易做成 PPT bullet list。

```
        标题：三件事里有两件是……                ← p .02~.16

    01   第一条              灰                ← p .22
    02   第二条              灰                ← p .34
    03   第三条              橙 ← 唯一焦点      ← p .46
```

反 PPT 做法：
- **不用「•」**，用 `01 / 02 / 03` 两位零填充序号，等宽排列
- 条目之间靠**行距**（≥ 2.4 倍字号）分层，不靠分隔线
- **只有一条被点亮成橙色**，其余保持 `#8a8a92`
- 每条不超过 12 个字；超了说明该拆幕

**升级形态 · 条目卡化**：条目 **≥ 4 条**，或条目本身是「清单 / 片名 / 账目」性质时，**必须**把裸文字行换成**微光条目卡**（Glow Row）——每条垫 `rgba(255,255,255,.025)` 圆角条、逐条错峰滑入，规格见 `style-spec.md` §5.4。裸行只配 ≤3 条的短列举。

## 6. 情绪粒子幕 · Flow

**用途**：信息密度最低的呼吸位。参考片用它承载"一次意外"这种语气转折。

```
  第 365 天                      H = 9.35 bit      ← 左右两角小字，p .05~.30
        （满屏流场粒子，参数见 style-spec §7.2）
                                                   
                    一次意外，                       ← 字幕 p .74~.88
```

- 这是**唯一允许全屏铺 layer** 的镜头，但要压到很低的存在感（线 alpha 0.30）
- 文字必须收在四角，**中央区域留给粒子**
- 建议放在情感转折点，不要两幕连着用

---

## 7. 档案墙幕 · Archive Wall

**用途**：「片名墙 / 清单墙 / 系列导航」这类 6~12 行条目的一次性摊开。它不是列举幕的加长版——
它有**账目大标签**当锚点、有背景点阵呼应进度，本身就是一个标准三层结构
（L1 暗淡点阵 + L2 微光条目卡 + L3 账目大标签 / 字幕）。

```
  第一笔账 · 命                      ┌ EP 03 ┐    ← 账目大标签(衬线) + 集数徽标, p .02~.14
  ▪▪▪▪▪▪▪▪ ······················               ← L1 暗淡点阵：格数=条数，第 i 格随第 i 条同时点亮

    01  睡眠欠账：每天 -2h                        ← 微光条目卡, p .16 起
    02  体检欠账：三年未查                           逐条错峰 0.24s
    03  情绪欠账：胃药常备      ← 仅此条点橙（.focus 焦点）
    04  ……
    07  ……                                       ← 6~12 条

                     字幕（一句收束）              ← p .74~.88
```

```css
/* 条目卡与点阵的规格直接复用 style-spec.md §5.3 / §5.4，此处只放档案墙的布局件 */
.arch .tag{left:150px;top:110px;font-size:58px;color:#b9b9c1;letter-spacing:6px}
.arch .ep{right:150px;top:124px;font-size:26px;color:var(--accent);letter-spacing:4px;
  border:2px solid #2e2e36;border-radius:8px;padding:8px 18px}
.arch .dots{left:150px;top:230px;opacity:.5}          /* 背景点阵：透明度再压半当 L1 */
.arch .rows{left:150px;right:150px;top:300px;bottom:170px;justify-content:center}
```

```js
/* 第 i 格点阵与第 i 条卡同时点亮：账本式的"逐笔记账"进度感 */
rows.forEach((r, i) => {
  const o = tw(p, .16 + i*.24, .34 + i*.24);
  r.style.opacity = o;  r.style.transform = `translateX(${24*(1-easeOut((p-.16-i*.24)/.18))}px)`;
  cells[i].style.opacity = o * .5;                     /* 点阵跟随条目，压半存在感 */
});
```

要点：
- 条目卡入场后**每条至少保证 1.2s 静止阅读时间**（末条点亮到幕尾淡出 ≥ 1.2s），因此**幕长放宽到
  10~14s**——这是对「幕长 6~12s」的幕式级豁免：静读时间优先。经验值：6 条 → 10s、8 条 → 12s、
  12 条 → 14s；超过 12 条说明该拆成两幕。
- 账目大标签用**衬线**，集数徽标用描边小框（`#2e2e36` 边框 + 橙字），像档案盒上的编号。
- 字幕照常 `p .74~.88` 入场，给整墙条目一句收束。

## 幕序编排的一般规律

参考片的叙事节奏值得直接照抄：

| 段位 | 用什么幕 | 作用 |
|---|---|---|
| 0 ~ 15s | **数字幕**（最炸的那个数字） | 钩子：先给结论，制造悬念 |
| 中段 | 公式幕 → 数据图幕 → 对比幕 | 论证：给数字找理由 |
| 情感转折 | 情绪粒子幕 | 呼吸位：让观众喘口气 |
| 收尾 15s | 数字幕 / 列举幕 | 落地：给一条能用的规则 |

> **永远以一个"能带走的东西"收尾。** 参考片最后落在"要一直出新。这是这个时代的通用法则"
> ——纯讲完理论，观众什么都不记得。

> **连续多幕同构时必须靠背景层区分**：如连续几个档案墙，L1 要交替（点阵 ↔ 流场 ↔ 气泡），
> 靠背景层的变化打破连播疲劳——同构的 L2/L3 加上同构的 L1 等于一张幻灯片放三遍。
